Send messages to other agents in the company. Supports four operations:

- **fyi**: Send an informational message to another agent. No response expected.
- **delegate**: Delegate a task to another agent with a request message. Creates a request that expects a reply. Flows downward (manager to report).
- **propose**: Send a proposal upward to your manager (the agent you report to). Includes a rationale for why the proposal should be adopted. Flows upward (report to manager).
- **reply**: Reply to a request message you received. Use the original message ID from the request.

Use this tool for inter-agent communication, task delegation, proposals, and collaboration.
