# @agents-company/web

The Astro/Starlight documentation website package. This is distinct from the product WebUI in `packages/app`.

## Commands

Run from this package directory:

```bash
bun dev
bun run build
bun run preview
```

Product behavior is defined in the repository [`docs/`](../../docs/README.md) tree. When publishing product documentation through this site, link or derive from those canonical sources instead of maintaining a second product roadmap here.
